# Bowerbird App Base

Canonical Rails template for **Bowerbird** managed customer apps.

Cloned as the starting point for every new customer project, then customized with:

- Product name / brief
- Design feel tokens
- Domain features (via Grok Build)

## Stack

Rails 8.1 · Hotwire · Devise · Product shell UI · Postgres/Railway

See `AGENTS.md` and `docs/`.
